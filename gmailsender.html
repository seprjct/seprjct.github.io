📧 GMail Sender

Сервис для отправки HTML-писем

🐍 Python

Описание

Утилита для отправки красиво оформленных HTML-писем через ваш аккаунт Google Gmail. Поддерживает шаблоны, вложения и кастомные заголовки.

  • Требуется Python 3.8+
  • Необходимо настроить App Password в Google Аккаунте
  • Все зависимости указаны в requirements.txt
